Methodology · AI V1
双层情报筛选方法
日报是知识库的每日视图；每条信号都沉淀为可跟踪、可验证、可行动的知识对象。

          

          
CORE RULE不能解释 AI 能力如何改变真实产品、Agent 工作流、基础设施或治理边界，就不进入 Core Signal。

          

            
Core Signal
明确涉及模型能力、Agent 产品、开发工具、企业应用、安全治理或算力基础设施变化的高精度信号。

            
Strategic Radar
尚未形成成熟产品，但可能改变 AI 产品入口、Agent 执行边界、企业采购或竞争格局的前置信号。

            
三层分类
Signal Type 决定进入哪个情报流，Content Type 描述载体形式，Information Type 描述事件本质，避免把“媒体报道”和“协议标准”混为一类。

            
证据优先
区分 confirmed、primary statement、reported、inferred 与 speculative，避免把高管计划或媒体报道写成已上线事实。

            
个人产品视角
额外评价工作流影响、产品可行动性、竞争影响和职业场景相关性；不代表任何公司或机构立场。

            
事件而非文章
同一事件关联官方、媒体、高管和技术来源；以一手来源为主，减少重复新闻卡片。

            
行动闭环
每条 Include / Watchlist 都要给出个人关注价值、产品机会、竞争风险、建议行动、待验证问题和后续触发器。

            
P3 仍可检索
低相关内容不推送但不物理删除，保留历史回溯，在后续信号出现时重新评估。
